## 1. 原则（硬性）

1. **论文的物理输入一律不改**：M=50、ν₀=−20、N_B=40、n_SR=3、ε^χ=2e-3、ε^SR=(1e-7, 6e-6, 5e-6)、r=(0.05, 2, 6)、F_P1/F_D0 渐近、s₀=2 GeV、α_s 与夸克质量、F₀ 网格 ni/50×0.163108、目标函数、Watson 定义、M_reg=10²（只作技术性先验界，见 W4）。
2. **只修两类**：(a) 离散化自洽——同一个连续量在等式两边必须用同一个离散定义；(b) 被截断丢掉的物理必要条件——振幅的每一个分波、在离散振幅有定义的每一点上都要满足幺正。不引入新的物理输入，不引入新的可调参数。
3. **数值参数（L_u、中点集合）由预先写定的收敛判据决定**，与论文吻合与否不参与任何选择。
4. **先登记后计算**：P_W 的定义与判据在修正案 8 中冻结（含 sha256）后才运行；与论文的比较只在 P_W 定稿之后，比较结果不回调任何设置。
5. **极值结论必须是双侧严格区间**：V1（Arb 中重算全部约束的可行点）给下界，V2（全空间对偶证书）给上界；每条结论标明验证级别。

## 2. P_W 的定义

变量、核、离散网格、全部约束与参数：同作者代码（c840933），以下四处不同。

- **W1 FESR 对偶区间自洽。** 两侧都积到第 n0 个节点格子的上边界 x_b = ν₀ + (8−2ν₀)/(1+cos(n0 π/M)) = 189.16，矩按 x_b^{n+n_ℓ} 归一。SVZ 右边是无标度的 c/(n+2)、c/(n+3)，形式不变。Gram 约束（x ≤ x_n0）与 FF 渐近上限（x ≥ x_{n0+1}）的分界本来就在 x_b，因此三者一致。这是一个 O(1/M) 的离散化修正，在 M=50 时与容差同量级（E5）；M→∞ 时 x_b → x_n0 → s₀，与原定义一致。
- **W2 全部分波幺正。** 对所有 ℓ < L_u、全部 M 个节点施加与代码相同的锥 \|h̃\|² ≤ 2 Im ĥ（Λ_ℓ 重标度同代码）。核即 L=L_u 的导出；Gram、手征、FESR、FF、𝔉 泛函、Watson 只涉及 ℓ≤3，不受影响。**P_W 取 L_u = 40**，收敛对照取 L_u = 60（ni=46）。若对照的 𝔉₁ 变化超过 1e-4（C1 的容差），P_W 改为 L_u = 60，生产重跑。
- **W3 节点间幺正。** 离散振幅在节点之间由圆盘插值唯一确定（与割线上的共轭核 K 一致）。P_W 要求在全部 M−1 个 φ 中点上，对 ℓ < 20 也满足同一个锥。用约束生成求解：每轮只加入被违背的（中点, 分波）。约束子集给出的是松弛，V2 上界仍然有效；V1 必须核验全部中点。停止条件：所有中点上 \|S\| − 1 ≤ 1e-6（V1 认证上界）。
- **W4 正则化只作技术界。** 保留代码的 ‖ρ/Mrho‖₄ ≤ 10²，用 ℓ∞ 外逼近（|ρ_i| ≤ R）编码。P_W 要求最优解满足 ‖ρ‖₄ ≤ R（于是它就是 ℓ4 问题的最优，区间闭合），且 R 的影子价格可忽略（放宽 10% 时 𝔉₁ 的变化 < 1e-6）。不满足就如实报告"P_W 仍受人为正则化影响"，附区间与影子价格。

求解：全空间（不降基，保证 V2 有效），SDPB 128 位。

- **P_W 无可行解**（新加的物理约束使问题不可解）：给出不可行证书（V2），结论写为"论文设定在物理完备下不自洽"，这本身就是一条严格结论。

- **算力不足**：探索用降基；结论只用全空间。
