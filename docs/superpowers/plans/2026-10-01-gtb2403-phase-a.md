# GTB 2403 Reproduction, Phase A (setup → kernels → solver → gate G3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an SDPB + Mathematica pipeline for arXiv:2403.10772 v4 whose kernels are derived and implemented by us, three-way verified, solved by SDPB and verified in Arb, and run it through gate G3 (Fig. 3 pre-Watson maxima).

**Architecture:** Mathematica package `mma/gtb2403/GTBKernels.wl` derives every linear map from the variables to partial waves, form factors, spectral densities and moments, and exports them at 40 digits. Python package `smatrix_bootstrap.gtb` builds the conic program from those exports, writes a degree-0 SDPB PMP, runs SDPB through the existing `sdp/sdpb.py` launcher, and re-verifies the primal in Arb with an independent kernel rebuild (`gtb/arbkernels.py`). The authors' notebook, run headless from a pinned submodule, is a reference only.

**Tech Stack:** Wolfram Engine 15 (Docker, `scripts/mma/wolfram.sh`), SDPB 3.1.0 (Docker, `scripts/sdpb/sdpb.sh`), Python 3.13 with numpy, mpmath 1.3, python-flint 0.9 (Arb), pytest.

**Spec:** `PLAN_SDPB_2403_ZH.md` (approved 2026-10-01). Phase A covers spec phases P0–P4; P5–P9 get their own plan after G3, because G3's outcome decides what P5 runs.

## Review Focus

- Index conventions (ρ₁ first index is the s-channel node; ρ₂ upper triangle with doubled off-diagonal coefficients; row blocks [I=0 | I=2 | I=1]). A silent transposition gives a "working" wrong program. Task A3 pins each with a closed-form single-entry test.
- The unphysical-region Legendre Q at arguments z < −1 (s* < 4): wrong parity or branch gives real but wrong chiral rows. Task A3 tests Q_ℓ(−z) = (−1)^{ℓ+1} Q_ℓ(z) and one hand-evaluated f(s*) row.
- Tiny absolute tolerances (S0 sum rule 1e-7 on targets 3e-7, entries down to 1e-21): unscaled blocks would be dominated by SDPB's error thresholds. Task A7 tests that every block is rescaled by its tolerance and that the scaling is an exact congruence.
- Equalities (c₁=1 per channel, 𝔉₀ = fixed) must be eliminated, never written as two inequalities. Task A7 tests that the eliminated program reproduces the equality to 1e-30 at random points.
- The ℓ4 regulariser: a relaxation (ℓ∞ or ℓ2 sandwich) must never be reported as the authors' constraint. Task A10 records which encoding produced each number, and the G3 verdict uses only an exact encoding or a bracket.
