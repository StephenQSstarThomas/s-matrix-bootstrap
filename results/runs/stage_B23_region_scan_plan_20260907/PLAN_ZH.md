# B2/B3 的最小区域交付方案

2026-09-07；仅制定计划，未启动优化。机器计划见 [scan_plan.json](scan_plan.json)。统一使用 M50 全变量、`stage_B_unitarity_resolved_20260906` 加新公共缓存 `stage_B_chiral_expanded_recover_M50_20260907/additional_scattering.npz`：10062 个有限散射行、五个解析尾条件和三个全区间 FG 多项式。原 8221 行的手征 x 支持区间后来出现 1841 个密集审核违例，不能作为新集合的可行下界；新公共输入上的 B1 尚未完成。

论文 §3.1（TeX 929–932 行，PDF 第22页）例示的是**从内点沿射线最大化长度**。令投影为 K、内点为 c，则支持函数与径向函数满足

\[
h_K(d)=\max_{p\in K}d\cdot p,\qquad
r_K(u)=\inf_{d\cdot u>0}\frac{h_K(d)-d\cdot c}{d\cdot u}.
\]

因此完整方向扫描恢复同一个凸集合，但论文射线角 α 不是 `--direction` 的支持法向角，两者不能逐角比点。支持扫描不需要先猜内点；零振幅虽可行，也不能未经证明当作严格内点。边界投影仍可能对应多个完整振幅。

1. **四方向开局、按缺口补点。** pure 和六个 ε 各先解四个正张成法向，共28个方向槽位；相同输入、方向、容差且已验收的支持结果可以复用。先完成 ε=.002，其他手征容差继续，pure 可作独立旁路。可行投影的凸包为内界，所有有效支持上界半平面的交为外界。四方向只保证获得有限外包的机会，不保证区域精度。外界必须非空、有界；缺方向或失败求解不得画成已完成的封闭允许区。
2. **预先固定误差单位。** pure 使用 q=(x,y)；手征使用 q=(x/xχ,(y+x/15)/ε)，其中 xχ=5/[16π²(92/140)²]=.07332139057，只来自论文物理单位与 Weinberg 关系，不取 PDF 黑点作拟合。以 q 空间 Hausdorff 外包距离 ≤.01 为区域目标、每个支持间隙 ≤.0025，同时保留原目标单位间隙 ≤1e−4。若 q=A p，单位度量法向 n 对应 CLI 单位法向 d=Aᵀn/‖Aᵀn‖；CLI 的 gap 应设 min(1e−4,.0025/‖Aᵀn‖)。这只规定数值分辨率，不改变物理可行集，也不代表论文原图精度。
3. **补点规则有明确停止条件。** 对外界各顶点 v 求其到内凸包的 q 距离，取最坏点，并以其至内凸包最近点的方向作为下一个度量支持法向。若主要缺口来自已解方向的宽支持区间，先收紧该方向；否则增加新方向。凸多边形外界到内界的最大距离出现在外界顶点，所以该规则可直接检验整个投影外包。最终用保存的方向、支持界和目标坐标包络作向外舍入，把目标及几何舍入误差计入 .01。时间上限与最多128方向只是运行保护，触及保护而误差未闭合仍为未完成。
4. **嵌套来自同一问题的约束包含关系。** ε 从 .0002、.0006、.001、.002、.004 到 .006，再到 pure，集合逐级包含。在共同原始法向上若 L_small>U_large，就是矛盾；小容差可行点也必须满足大容差全部已知支持上界。可合法把小区域可行点并入大区域内包、把大区域外包与小区域外包相交，保留传播前数据以暴露矛盾。不要要求 U_small≤L_large 或“小外包完全落入大内包”，真实区域可能接触。所有区域须使用同一公共行集；后来若新增物理行，显式更新共同版本及受影响支持记录。FG 切点增加只是在分离同一个全区间必要条件，不改变目标集合。

在这套公开条件定义下，B2 的交付是完整 pure 区域的内外界，B3 是六个容差的完整区域、嵌套、参考线及点；均保存每个可行振幅、原式支持区间和现有物理接受状态，并满足上面的封闭与误差条件。Fig.4 的 x>0 是最后的展示裁切，不能偷偷加入优化约束。Fig.3 的纯 S 区域在论文 §4.1 明说后续不再使用，不必阻塞手征到 QCD 的主线。

这可以称作**所声明有限模型下 B2/B3 的条件版本完成**。原作者的插值、密度约束处方和手征范数仍未恢复；论文 Fig.3 明示 M50/L10，本计划使用 L12 加额外行的加强模型。即使曲线近似重合，也不能称为精确原图复现，更不能把有限采样加首项必要条件称为连续幺正认证。缺失处方、离节点检查、积分误差和后续收敛的适用范围维持当前 SCIENCE 定义，不另起一套幺正性审核。

JSON 中的 `base_argv + job.argv` 是现有单一 CLI 可执行命令，输入路径已核对，28个初始法向及 gap 已数值展开。当前 `regions` 可筛选相同模型的合格支持报告、聚合及画图；它还不计算上述带舍入的 Hausdorff/嵌套验收。因此自适应方向选择与几何验收是一个小的区域后处理接线，不能把现有画图成功当作这项验收已经实现。所有论文点只在数值方案冻结后作比较。
