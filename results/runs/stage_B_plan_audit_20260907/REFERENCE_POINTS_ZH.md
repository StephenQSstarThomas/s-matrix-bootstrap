# Fig.4 两个参考点的现有包络判定

基于当前汇总快照 [partial_25](../stage_B3_PV_B377500_region_20260907/partial_25/regions.json)。仅使用该快照接受的可行点、目标坐标包络和支持上界；未新增求解、指标或源代码。可更新数据及全部证据路径见 [REFERENCE_POINTS.json](REFERENCE_POINTS.json)。

固定条件为 PV M50/L10、1500个原生幺正盘、3876变量、sampled/free、B377500和两个四维L2手征球。结论属于这个条件有限问题，不能转移为连续幺正性或联合QCD可行性。

**唯一未定项：ε=.001的140/92公式点。** 它在现有内包边(5→1)外侧，定向面积为约−1.37196027e−9；这只排除了当前内包，不排除整个允许区域。全部现有有效外半平面仍容纳该点，逐条余量已保存。因此当前不能写成“允许”或“排除”。

PDF黑点另使用既有读数尺度δx=1.9507737650e−6、δy=2.5750564548e−7检验，整个读数矩形保持同一分类；其中ε=.001的三角形最小权重下界仍约.05623455。该读数尺度不是原作者solver误差，也不是物理输入置信区间。

这已支持一项具体条件结果：ε=.002同时容纳PDF黑点与140/92公式点，而ε=.0006/.0002排除二者。它不要求整体区域几何已收敛，也不意味着B3整体完成；尚未确定的来源设置及其它图形差异仍保留。
