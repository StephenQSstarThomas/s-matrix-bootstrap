# C3：Fig.7手征相移复现完成

使用C2锁定的同一套3876系数，从原M50节点取0.28–1.2GeV内43个能量并加精确阈值；S0/S2/P1共132个所列能量／波检查通过。归一化是S=1+iπ√(1−4/s)f，δ=unwrap(arg S)/2，从阈值δ=0锚定，η=|S|；没有用arg f代替δ，没有强制η=1，也没有构造PV离节点延拓。

上表是各自原图拟合曲线可用范围内、非均匀原生节点上的描述性误差，不是χ²或新的验收门槛。S0中能区有约16.5°的最大偏差；接近1GeV及以上的S0实验结构也没有被当前IR-only代表解再现，原paper手征图本身在该处已有偏离。S2较贴近，P1则与实验的ρ共振显著不同：本解在E≈.792GeV处δP1≈5.29°，到≈1.199GeV仍仅≈8.51°。

这复现了论文C阶段的重要对照：手征约束能较好组织低能S波，但本次预选代表解没有给出正确P1；后续应按D/E联立电流、形状因子和UV求和规则，再比较P1变化。它不证明整个手征可行集都没有ρ，也不证明UV是唯一可能增加的信息。

全部计算没有重新选点、改变系数或拟合物理参数。代表振幅来自有误差说明的可行边界插值，因此不宣称与原作者的精确极值振幅相同。原始1500盘的完整可行性见C2 selection.json；本次132个主波／能量求值也通过，但不扩大为全能量全自旋连续认证。
