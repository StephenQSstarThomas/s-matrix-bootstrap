# 对「未完成核心claim台账与P0–P5计划」的科学审计

审计对象：`results/runs/major_claims_20260912/{CORE_CLAIM_LEDGER_AND_PLAN_ZH.md, CLAIM_LEDGER.json, MAJOR_CLAIMS_ZH.md, final_report/REPORT_ZH.pdf(17p), PLAN_ZH.pdf(4p)}`。对照论文 TeX `references/2309.12402v3-source/prd_submission_2.tex`（下文 L 为其行号）、数字化原图 `references/figure*.csv`、仓库自身 JSON。只读，未运行任何计算。

## 0. 结论先行

1. **台账对论文的描述基本准确，但把差距归因于"作者数值合同/producer未恢复"不成立。** 仓库自己的数据已把 Fig.3 纯散射区域复现到 3 位有效数字（x∈[−2.9025,2.2349] vs 原图 [−2.9020,2.2329]），散射 producer 不是问题所在。
2. **真正的原因可在仓库自己的 JSON 里直接读出：raw 逐矩 .002 盒使 P1 的 n=−1 矩和 S0 的 n=0 矩分别松到 ±47% 和 ±84%，优化器把这个松量填成低能非两π谱重，ρ 读数被拖低。** 七份振幅的 90° 读数与 √(P1 n=0 矩 / n=−1 矩) 逐一吻合（误差≤2%），而论文打印矩比给出 822 MeV，正是论文三条曲线的 813–827 MeV。作者在 TeX L897 自己写过这个估计（"E_P1=820 MeV … very roughly agrees with the ρ"）。
3. **两条"严格排除证书"是关于仓库可行集 D 中厚度 1e−6～3e−5 的一层的命题，且该层完全落在论文区域之外**（仓库 tip x=0.0991，论文 tip x=0.0811；仓库 ref 点比论文同 x 上边界高约 1.6e−4）。它们证明的是 D≠D_paper，不是论文有问题。台账有部分承认，但标题级措辞"排除原图相应相移符号"仍是误导。
4. **P0–P5 没有任何一步回到论文 SDP 形式用成熟求解器直解，也明令禁止检验 FESR 误差合同这一唯一被数据指向的假设（称之为"贴图"）。** P1 以"取得作者 2309 矩阵"为前提，而作者 README 明言 2309 无公开代码——该前提永远不满足，计划因此无法闭合。

## 1. 六项"未闭合"逐条审

### 1.1 三代表 ρ（major）

**描述准确性。** 论文要求：tip（红点）与靠近手征黑点的两点（pink、light pink）三条 P1 曲线"coincide both at low and high energy but spread in the middle"（L1148, L1172），90° 穿越比 770 MeV 高约 6%（L1149）。数字化原图 90° 穿越 812.5/824.3/826.6 MeV（`figure9_p1_phases.csv`）。台账引用无误。

**归因。** 台账说"须恢复或澄清会改变 D/代表区域的真实来源细节"。但看 `tip/mid/ref_refine_01/joint_audit.json` 的 `moments` 与 `refined_phases/phases.json` 的 `moment_budget`（raw 单位，目标±.002）：

| 振幅 | P1 n=−1 矩（目标 .004228） | 其中非两π部分 | P1 n=0 矩（目标 .14571） | √(n=0/n=−1)·140 MeV | 90° 读数 |
|---|---|---|---|---|---|
| tip | .00443 (+5%) | .00020 | .14771（贴上边） | 809 | 803 |
| mid | .00591 (+40%) | .00143 | .14771（贴上边） | 700 | 701 |
| ref | .00609 (+44%) | .00181 | .14771（贴上边） | 690 | 696 |
| L8/L12 | +2%/+9% | — | 贴上边 | 819/793 | 835/789 |
| M45/M60 | +22%/+16% | — | 贴上边 | 750/768 | 749/774 |

论文目标矩比 √(.14571/.004228)·140 = 822 MeV。ref/mid 的两π部分（.00428/.00447）几乎恰等于目标，多出的 40–44% 全是非两π谱重（`phase_penalty`），这正是 ref/mid 的 min η_P1 低到 .24/.43 的来源。2403v1 §8.5 明言 2309 的 1.2 GeV 计算"已近乎饱和幺正性"（`ITERATION_SCOPE_ADDENDUM_ZH.md`），即作者的解没有这种谱重。**结论：三点分散不是"作者合同未知"的神秘后果，而是 raw 盒对 n=−1 矩的 47% 松量被 y 方向最大化利用的确定性后果。** 台账 §7 写过"两矩比给出平均能量平方"，`PV_PRIMARY_SOURCE_AUDIT` 提到"约 822 MeV 的矩均值尺度"，却拒绝把它与自己的矩数据对照。

### 1.2 S0/S2

描述准确（论文 L1172：三条 S0 低能重合、高能分散；末节点 1.1957 GeV 相移 99.6/87.3/106.4°，`figure10_s0_phases.csv`）。归因同上：S0 n=0 矩在七份振幅中全部 +51%～+84%（tip 贴上边 .00437 vs 目标 .00239），S0 谱均能从目标 959 MeV 压到 713–788 MeV，低能标量谱重过大，S0 相移自然过快上升（tip 在 1.2 GeV 达 175°）。"UV 加入后与原文 S0 曲线相符"缺的不是来源，是把 n=0 矩盒收紧。

### 1.3 Fig.11

数值核对无误（原图 L 跨度 12.539、M 跨度 54.349 MeV，`figure11_p1_phases.csv` 复算一致；仓库 46.210/54.064 由 `F_refined/resolution.json` 复算一致）。归因错误：上表显示 L8/L10/L12 的读数差异同样由 n=−1 矩松量 (+2/+5/+9%) 驱动；论文 Appendix A（L1208）的"reasonably good convergence"在矩被钉住时才有意义。台账"先解决名义 M50/L10 的来源问题"是对的，但"来源问题"就是误差合同，不是 producer。

### 1.4 Fig.8 不对称

论文 L1145/L1148："upper boundary shrinks notable but the lower not so much"。数字化原图在 x≈.0733 处：上侧收缩 2.3e−4，下侧 3.3e−5（比≈7）。仓库 `refined_regions/regions.json reference_section_certificate`：上 1.96e−4、下 1.82e−4，比 [1.005,1.094]。**上侧量级与原图一致，下侧多动了 5.5 倍**——这是可量化的失败，台账却以"原文没有给统一误差阈值"回避。下侧过度上移同样与低能谱重自由度过大相容。

### 1.5 Fig.3–6

台账称历史区域"geometry_ready"故不算未完成，遗漏了核心事实：**Fig.3 纯散射区域已精确复现，而 ε=.002 手征区域右端 0.1059（separate）/[0.1008,0.1059]（combined，`B_combined/FIG4_CORE_CLAIMS_ZH.md`）比原图 0.0826 大 28%，六个 ε 全部超出 .011–.028。** 这一组事实本身就把差距定位在手征/正则化层而非散射层。台账把原图范围差异归为"原图最大显示值不是数学排除界"，但 22–28% 的差异是 36 个标记半径（x 轴 1e−4/pt），不是读图误差。

### 1.6 作者数值合同（source-critical）

逐项对照论文原文：

- **χ 范数**：L951 确写"with some norm"。但仓库自己的 `CHIRAL_SOURCE_RESIDUALS_ZH.md` 用原图 Fig.5 曲线算出合并 8 维 L2/ε = 1.000007/1.000020/1.000146（三色都贴球面），与 2403 代码 `norm([r01;r21])<=echi` 一致；SCIENCE.md 也承认"combined-L2 成为最有依据的读法"。2026-09-11 却以"输出辅助推断"为由改回 separate-L2。更关键：E3 combined 分支（`E3_PAPER_RESULT_ZH.md`）ρ 读数 788.6/700.4/696.3，与 separate 的 803/701/696 几乎相同，**χ 分组不是 ρ 差异的原因**，台账把它列为待恢复合同是转移焦点。
- **密度正则化**：论文 §3.1（L926–929）变量表 {T0,σ,ρ} 之后没有任何范数界；"2309 密度正则化的具体取值"根本不存在，B=377500 是从 2403 代码搬来的仓库约定，而且是**活跃约束**（B/2 使 UV tip 上界从 .0991 降到 ≤.0935）。称其为"作者约定未恢复"是范畴错误。
- **FESR 误差**：L1030–1033 写 ‖(π/M)Σ… − QCD value‖≤ε^SR，"QCD values are those from (2.56)"，而 (2.56)（L876–881）是除以 s0^{n+2} 的归一化矩。raw 求和减归一化目标量纲不一致，"直接读法"其实要求仓库自己把目标乘回 s0^{n+2}——这已是一个选择。其后果是四矩相对容差 84%/1.8%/47%/1.4%，与 L1033"enough information of the sum rule is put into the bootstrap"直接冲突；2403 代码对应容差为目标的 11–48%（`PV_PRIMARY_SOURCE_AUDIT` §3 表）。"raw 逐矩盒是原式直接读法"的说法把一个可疑读法包装成中性事实。
- **散射 producer**：论文 §3.1 只给变量和"用 (fdef) 求分波"，确未唯一指定核。但 Fig.3 到 3 位数复现说明这一层已经等价；台账把它并列为 source-critical 缺口没有数据支持。

## 2. "严格排除"陈述的逻辑审查

两条证书（`tip_S0_certificate_final/probe.json`、`ref_P1_exact_section/probe.json`）的数学本身无误：D_L={q∈D: n·p(q)≥L} 上 O(q)≤U_γ+c−γL。问题在于 D_L 是什么、D 是什么。

1. **D_L 是一层薄片。** S0：`required_anchor_loss_lower`=3.45e−5，即排除区为 x∈[.099061,.099097]；P1：4.86e−4/n₁=500 → Δy≈1e−6；"精确 xref 截面"再放宽到 |Δx|≤1e−10、Δy≤1e−8。台账/STATUS 用"整个近支撑区域""全域排除"描述厚度 1e−6～3e−5 的层，措辞夸大。
2. **该层在论文区域之外。** 论文 UV 区域 x≤0.0811（红点即 tip，`figure8_selected_points.csv`），仓库排除层在 x≥0.0991；论文在 x=.0733 的 cyan 上边界≈−.00448（`figure8_boundary.csv` 插值），仓库 y_in=−.004314，高出 1.6e−4（约 2.5 个标记半径，方向与 x 方向 22% 超出一致）。因此"Im S1(.7317 GeV)<−.5055 与原图约 30° 不兼容"比较的是论文可行集之外的点与论文的点。
3. **证书恰是 D≠D_paper 的证据。** 在仓库 D 内，y 最大化把 n=−1 矩推到盒顶、ρ 降到 690 MeV，于是 .7317 GeV 处相位已过 90°、Im S1<0——这是 raw 盒的确定性后果，不是论文的"障碍"。
4. **台账是否承认？** 部分承认：MAJOR_CLAIMS §6"不是这样的无条件结论"、台账"不是整个 D 内所有振幅、所有原参数实现…的排除"。但 STATUS 顶部"它们排除原图相应相移符号"、报告首句"推进为两条针对整个近支撑区域的严格排除证书"、台账"这是当前 D 及原几何区域的严格障碍"仍把仓库内证书写成对论文的判定，且从未说明排除层与论文区域不相交。

## 3. P0–P5 计划评估

- **P0（锁定来源）**：可执行但无产出——它是一张分类表。其"完成条件"要求"每个会改变 D 的选择都有可核验来源"，而 2309 无公开代码（作者 README "No public code was provided at the time"），此条件对 χ 分组、FESR 尺度、B 三项永远不可满足。P0 实质是把"不做检验"合法化。
- **P1（拿作者矩阵核对）**：以"若取得作者 2309 矩阵或完整点"开头，是对不存在之物的条件句。现实路径是：用作者公开的 2403 Mathematica 生成器（仓库已存 `references/upstream-gauge-theory-bootstrap/theories/qcd/papers/arxiv-2403.10772/GTB_numerics.nb`）按 2309 参数（ν0=0, M=50, L=10, s0=1.2 GeV, 两通道四矩, combined χ）生成核，再用 CVX/MOSEK 或 CVXPY+Clarabel 直解。P1 只把 MMA 用于"独立公式核对"，明确排除生成 producer 的用途。
- **P2–P4**：全部沿用 Newton/PV/B/raw 盒（"只实施 P1 已定位的真实差异""复用已认证几何/支撑""重新运行本轮两个预定分量探针作为审计关卡"）。P5 停止规则写明"不能继续更换误差范数、B…来贴图"——这恰好禁止了 §1 指出的唯一被数据支持的假设。CLI `--sr-error` 只有 raw-absolute / normalized-absolute（run.py:244），后者为 .002×s0^{n+2}，等于不加约束，从未运行；不存在相对容差选项。
- **是否有"回到论文 SDP 形式用成熟求解器直解"的步骤？没有。** `SOLVER_DECISION_ZH.md` 自认：全空间 Clarabel 两次 MaxTime/一次 NumericalError 后被放弃，"没有同题 MOSEK 对照"；问题规模（4076 变量、1500 个 2×2、100 个 3×3、少量 SOC）对 MOSEK 是分钟级，而仓库每个支撑点用 900 s 上限的自研 Newton 多轮续算，再用 Arb 做证书，把工程复杂度堆在与物理差距无关的地方。

**判断：该计划注定在同一模型内打转。** 它把可以在几小时内穷举的三项离散假设（χ 合并 vs 分离；FESR 容差按 raw/相对/2403 式；B 有/无或取值）改写成"等待来源"的无限期条件，同时禁止假设检验。合理的做法是预登记的假设检验：例如固定四矩相对容差 10%（或 2403 的 11–48% 比例），预测 ref/mid 的 ρ 应移到 822±40 MeV、η_P1 接近 1、S0 谱均能回到 ~950 MeV——这不是拟合相位，是检验一个由论文原文（L1033、L897）和仓库自身矩数据共同支持的假设。

## 5. 结论

台账的数值可信度高：每个数字都能在 JSON 与数字化原图中复核，没有发现伪造或算错。它的科学可信度低：对论文的三处关键理解有偏（把 2403 的 B 当成 2309 合同、把 raw 盒当成"直接读法"、把 χ 范数当成未知而无视自家指纹证据），并且用"producer 未恢复"这一不可证伪的说法覆盖了一个仓库自身数据已经指认的具体原因——raw 逐矩 .002 盒使 P1 n=−1 与 S0 n=0 矩几乎不受约束，优化器用低能非两π谱重填满松量，ρ 与 S0 随之偏离；论文打印矩比 822 MeV、作者自己的 820 MeV 估计、论文 813–827 MeV 的三条曲线、2403 对 2309"近乎饱和"的描述，四者互证作者的四个矩都被有效钉住。散射层已由 Fig.3 的三位数复现证明等价，"完整散射 producer"不是缺口。

两条"严格排除"是关于仓库可行集边界薄层的正确定理，该薄层位于论文区域之外 22%（x）与 1.6e−4（y），它们证明的是仓库模型与论文模型不同，不能写成"排除原图相移"。

P0–P5 的根本缺陷：以不存在的作者矩阵为前提，禁止对误差合同做预登记检验，不使用成熟 SDP 求解器，继续在自研 Newton/PV/B/raw 盒模型内收紧无关精度。真正需要做的一件事：用作者公开的 2403 核生成器按 2309 参数生成矩阵，以 MOSEK/Clarabel 直解 combined-χ 且四矩按相对容差钉住的 SDP，看 ρ 是否落到 822 MeV 附近——这一小时级的实验会一次性判定"合同"与"物理"哪个在负责。
