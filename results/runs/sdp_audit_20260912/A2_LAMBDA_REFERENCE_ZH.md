# A2 / D1：λ 标量参考值的适用范围

日期：2026-09-12。范围：只读源码与一手文献审计、代数推导；没有新优化、分辨率阶梯或数值外推。**本记录不宣称 A2 / D1 的数值收敛任务完成。**

结论：`projector.lambda_row` 的耦合归一化正确；其说明中“2.661 是 exactly this setup 的独立已发表数值”没有得到所引文献支持。2.6613 是**单个完全交叉对称标量振幅**的数值最优参考。完整 O(3) 振幅的中性通道满足该标量问题的必要条件，因此得到单向上界；文献和该投影均没有证明 O(3) 极值必须达到这个数。

[1708.06765v1，§3、§4.2，Fig.6–8，Eq.(19)–(24)](https://arxiv.org/html/1708.06765#S4.SS2)：研究两个相同实标量的单个振幅。§4.2 排除阈下束缚态极点，定义 \(\lambda=\mathcal M(4/3,4/3,4/3)/(32\pi)\)。本地 `references/1708.06765v1-source/PaperIII_v11.tex` 第 620–629 行定义该问题；第 640–663 行讨论加入阈值 \((s-4)^{-1/2}\) 奇性后出现的 2.6613 数值平台，并将其描述为预期的最优界。该段把 2.75 称为已有严格上界，**没有把 2.6613 的全部小数称为已证明的精确常数**。

## 2. 完全一致的归一化

记 \(A_s=A(s,t,u),A_t=A(t,s,u),A_u=A(u,t,s)\)。2309 的张量分解给出

\[
T^0=3A_s+A_t+A_u,\qquad T^2=A_t+A_u,
\qquad B:=T_{33,33}=A_s+A_t+A_u=\frac{T^0+2T^2}{3}.
\]

由 \(A(s,t,u)=A(s,u,t)\) 可知 B 对三个 Mandelstam 变量完全对称。以论文的同一投影定义中性分波，得到

\[
f^{33}_\ell(s):=\frac14\int_{-1}^{1}P_\ell(\mu)B(s,t,u)\,d\mu
=\frac{f^0_\ell(s)+2f^2_\ell(s)}3.
\]

仅偶数 \(\ell\) 非零。令 \(\kappa(s)=\pi\sqrt{1-4/s}\)，则

\[
S^{33}_\ell=1+i\kappa f^{33}_\ell
=\frac{S^0_\ell+2S^2_\ell}{3}.
\]

1708 的 §3 Eq.(10)–(11) 在四维给出
\(S_\ell=1+i\sqrt{1-4/s}\int P_\ell\mathcal M\,d\mu/(32\pi)\)。代入 \(\mathcal M_{33,33}=8\pi^2B\)，即为上式，没有遗漏 \(\pi\)、2 或 3 的系数。

在 \(*=(4/3,4/3,4/3)\) 处三个 A 相同，故

\[
\lambda=\frac{\mathcal M_{33,33}(*)}{32\pi}
=\frac\pi4B(*)=\frac{3\pi}{4}A(*).
\]

这正是 `src/smatrix_bootstrap/sdp/projector.py` 原第 162–188 行实现的泛函。其第 171–174 行的参考身份判断应与归一化正确性分开。Weinberg 振幅直接给出 \(\lambda=m_\pi^2/(32\pi f_\pi^2)\)，提供独立代数归一化检查；它不决定纯散射最大值。

## 3. 精确 disk 方差恒等式与单向集合包含

对每个物理 s 和偶数分波，展开平方即可得到

\[
\boxed{1-|S^{33}|^2
=\frac{1-|S^0|^2}{3}
+\frac{2(1-|S^2|^2)}3
+\frac29|S^0-S^2|^2.}
\]

于是 \(|S^0|\le1,|S^2|\le1\) 严格推出 \(|S^{33}|\le1\)。最后一项保留了同位旋通道之间的差异；中性通道单独的 disk 没有要求它为零。反向逻辑不成立：仅在单个分波值的代数层面，\(S^0=2,S^2=-1\) 给出 \(S^{33}=0\)，后者通过中性 disk，前者违反 O(3) disk。这是约束不等价的例子，不是声称构造了一个全局解析反例。

还有一个必要的饱和条件：若完整 O(3) 点满足 \(|S^{33}|=1\)，右侧三个非负项都必须为零，故

\[
S^0=S^2=S^{33},\qquad |S^0|=|S^2|=1.
\]

因此把一个数值上接近弹性的单标量极值解扩充为完整 O(3) 振幅，需要额外的通道兼容性证明。简单令 \(A=B/3\) 并不自动可行：此时 \(f^0=5f^{33}/3,f^2=2f^{33}/3\)，如中性波有 \(S^{33}=-1\)，则 \(S^0=-7/3\) 已经违反幺正性。这个代数检查同样不证明两种问题的最优值必然严格不同。

准确的集合结论是：令 \(\mathcal K_{O(3)}\) 为满足全部能量、全部分波以及相同解析性和极点假设的完整 O(3) 振幅集合；令 \(\mathcal K_{\rm scalar}\) 为相应单标量集合；令 P 取中性通道，则

\[
P\mathcal K_{O(3)}\subseteq\mathcal K_{\rm scalar},\qquad
\sup_{\mathcal K_{O(3)}}\lambda\le
\sup_{\mathcal K_{\rm scalar}}\lambda.
\]

右边的已发表**数值参考**约为 2.6613。该包含关系没有给出等号，也不单独证明严格小于。要证明等号，至少需要 O(3) 可行振幅序列达到标量上确界，或等价的扩充/极值证明；所引文献没有提供它。当前仅在有限节点和有限分波上满足约束的解，也不能直接作为上述全局集合的元素使用。

## 4. 对 A2 / D1 停止规则的影响与保留任务

任务书第 97、149 行的“外推明显低于 2.661 ⇒ 算子或参数化错误”不成立：即使已严格求得 O(3) 极限小于标量上确界，也仍与上述必要上界相容。这个来源纠正不证明当前算子正确，不排除参数化误差，也不支持把已测差异全部归于求解器。

此外，固定 \(L\) 时的 \(M\to\infty\) 仍不是全部分波的极限。对固定光滑密度的求积误差阶，不能直接移作优化值误差阶；还需要覆盖优化序列的统一正则性/系数控制、可行集近似与可行恢复估计，以及数值求解误差界。标量参考论文的 Fig.6–7 恰好显示阈值奇性及基函数选择显著影响收敛，不能从它推导本离散普适的 \(1/M\) 外推律。

因此后续仍需区分三件事：当前 O(3) 有限问题在声明的 M/L、正则化和插值处方下的有效最优值区间；这些区间随分辨率的经验变化及外推假设；若另外实施单标量校准，其约束集合须与参考真正一致。任何 \(1/M\) 拟合只能在这些身份与误差已明确时作为有假设的数值估计，不能凭低于 2.661 触发算子已被证伪的结论。本次没有完成这些新数值计算，也没有证明该参数化的渐近极值或收敛阶。
