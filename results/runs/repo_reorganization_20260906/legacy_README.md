# Historical evidence

`legacy/` contains the former source modules, experiment scripts, tests,
long derivations and optional Julia work. Every moved or copied file was
checked against its original SHA256. See [source_manifest.json](source_manifest.json).

Numerical results and primary references remain in their original workspace
locations. Two directory links preserve archived documents' relative data
and reference links. Embedded run-source snapshots remain unchanged.

Historical commands belong to their recorded source version and path layout.
For exact historical replay, restore that snapshot and its recorded paths
in an isolated checkout. Do not mix old scripts with the new active package.
Current work uses the ten-file core and root science/status summaries.
