0\le u_{Ii}\le2/\kappa_i .

这里 r 必须为实际双谱独立分量，rho2 非对角 C_flat 先除2；D 必须采用本轮解析行。固定 M、B 有限且每个原生 \(\kappa_i>0\)，故

**最小措辞修正：** [HELD_INTER_NODE_ISSUE_ZH.md](HELD_INTER_NODE_ISSUE_ZH.md) 第31行“密度L4界使固定M的系数有界”应明确为“L4界与原生散射盘、自由列恒等式共同界定全部系数”。L4 单独不限制 T0 或单谱。另，“保留3876个参数”不等于已经证明整个函数表示没有冗余；这里的紧性和严格凸性不要求后者。

## 3. 其余结论的准确等级

- **解析恒等式／有限定理：** DERIVATION 第2、4、5、7节的坐标代数、自由列、严格 IR 种子和 Gauss 余项论证；HELD 第6节用支配收敛得到 \(f^0_0(\infty)=5T_0/2,\ f^2_0(\infty)=T_0\)，从而 T0=0 是当前族全能量幺正性的必要条件。这些均限于声明的有限函数族；必要条件不是充分条件。第5节的正 Q_l 积分证明只用于 s>4 的有限保留节点。
- **认证数值见证：** 完整 C 的原生解析可行性、固定 C 的负 Farkas 界及节点间严格负幺正余量。它们证明所检查点／指定 C 的结论，不证明所有允许振幅、所有能量或原论文未知实现的结论。9项源行乘积对照是交叉检查，不能单独替代全部算子项的推导及认证数据包络。
- **条件性闭包结论：** 旧有限证明第124–132行的高能 R 消元论证也可由同一 Schur 代数重新用于新族；要得到投影闭包相等，必须有同一约束下的严格高能散射点。上述严格约化见证补足了该前提。闭包支持上确界相同不保证每个边界点都能用有限 R 提升。
- **弱对偶：** 新自由列验证、实际 rho 打包和本轮算子误差处理都不可省略。认证负界排除固定完整 C 的全部电流扩展，不排除整个模型；弱对偶不需要满秩或 Slater。另，[FOUNDATIONS_PROOFS_20260910.md](../../evidence/FOUNDATIONS_PROOFS_20260910.md) 第337行的盘支持 \(\sqrt{k_R^2+k_I^2}+k_I\) 只适用于坐标 \((\kappa\operatorname{Re}f,\kappa\operatorname{Im}f)\)；若直接用 f 坐标，必须整体除以 κ。建议给该引用补明归一化，不能凭符号名字转移旧对偶。
- **数值停止而非极限定理：** Newton decrement、支持 gap 和最后两层 μ 的变化是三个不同的证据。它们不证明 μ→0 的唯一极值幅度或相位误差界。当前文档已正确保留该限制；本复核不额外扩大其物理结论。

本意见仅补足证明适用条件和证据分级；没有发现需要引用 PV 满秩或旧 sine 秩结论才能维持当前有限原型的论证。
