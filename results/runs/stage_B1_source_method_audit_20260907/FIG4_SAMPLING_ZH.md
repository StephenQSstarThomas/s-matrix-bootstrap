# Fig.4 显示采样与 +x 支持的比较审计

日期：2026-09-07。对象为 He–Kruczenski **2309.12402v3** 的 Fig.4，尤其绿色 εχ=.002；本次只读取论文、已有 PDF 矢量中心和已有支持结果，并计算几何诊断。未优化模型、改变 regulator 或修改核心代码。

**结论：图上的 .082573 是最右显示采样点，不能当作论文真实 +x 支持的严格上界。径向角与支持法向确实不同，但完整扫描应给出同一凸集，不能据此自动消除 .02331 的差异。** 普通显示裁切及矢量中心读数误差可以排除；观察到的近等 x 网格和条件凸性诊断也不支持把整个差异直接归于“一两个遗漏角度”。不过作者没有提供实际扫描中心、步长和原始求解误差，因此仅凭这些点也不能严格排除较大的漏尖端或边界误差，更不能据此宣布论文错误。

## 1. 原文说明了什么

[§3.1 的原 TeX，第 931 行](../../../references/2309.12402v3-source/prd_submission_2.tex#L931)说明：在凸投影区域内部选中心 (a,b)，固定 α，施加

\[
x=a+t\cos\alpha,\qquad y=b+t\sin\alpha,
\]

最大化 t，扫 α∈[0,2π] 得到边界。这里是一种明确给出的示例方法；该段**没有给出实际中心、角步长、射线数量，亦没有说明 Fig.4 必须使用均匀角网格**。不能把“约 120 个显示点”转写成“每隔 3° 求一次”。

[§4.2，第 1073 行及 Fig.4 图注，第 1083 行](../../../references/2309.12402v3-source/prd_submission_2.tex#L1073)明确只显示 x=f⁰₀(3)>0 的相关一侧。因此，将 B3 汇总窗口定义为 `published_positive_x`，在完整支持问题求解后用 x≥0 截取内外凸多边形，属于恢复论文的显示范围。保留全平面 oracle 和负 x 解并不矛盾；要求 Fig.4 本身同时复现未显示的负 x 侧则是额外范围。原文没有声明进一步删掉绿色区域的正 x 尖端。

对于**同一个**紧凸集 K，支撑函数 h(n)=max\_{z∈K} n·z 与足够完整的内部射线扫描是两种等价的边界表示。相同数值的 α 和法向角通常对应不同边界点；但比较全体显示点的 max x 已经不涉及逐点角度配对。

## 4. 实际差距及凸性能够提供的条件诊断

[当前 PV/midpoint 同题支持](../stage_B_pv_chiral_M50_barrier_20260907/report.json)使用 M50/L10、原 1500 个采样幺正约束、自由 T₀、ordinary 双密度 l4 上限 B=377500、两组四维手征 l2 约束 ε=.002，独立原 H 给出

\[
h(+x)\in[.10588509849925652,.1059401757842492].
\]

这是**本项目明确有限问题**的区间，并不证明 B 和所有处方就是生成 v3 图形的设置。既有 [finite-sine 同题区间](../stage_B_prototype_reused_chiral_M50_20260907/report.json)为 [.1058808058047516,.10592808800420311]；两种核的这个支持值近乎相同。

与绿色 maxsample=.08257301276510262 相比，PV 可行点的 x 差为 **.0233120857342**：相当于参考值的 **28.2321%**，或当前值的 **22.0164%**；两个分母不可混写成一个精确百分数。这个差距约为显示 x 网格的 **16.0924 步**，或中心读数尺度的约 1.20 万倍。

### 4.1 理想“显示点都位于精确凸边界”的最后割线诊断

令上边界 u(x) 为凹函数、下边界 l(x) 为凸函数。对最后两个上点、最后两个下点，向右的割线斜率分别为

\[
m_u=-.1374087898,\qquad m_l=-.0310449830.
\]

如果这些点是精确边界值，则在它们右侧有

\[
u(x)\le y_{288}+m_u(x-x_{288}),\qquad
l(x)\ge y_{344}+m_l(x-x_{344}).
\]

两条延长线交于 x=.0846969580。因此在这一**附加理想假设**下，可能遗漏的尖端延伸至多约 .00212395，只占当前 .0233121 差距的约 **9.11%**。在当前 x=.1058851，两条割线分别要求 u≤−.00845829、l≥−.00620464，已无交集。

**这不是从论文得到的严格上界。** 图中上边点相对其凹包络的最大向内偏差约 3.44432×10⁻⁵（点 286），下边对应凸包络最大偏差约 1.04364×10⁻⁵（点 339）。所以把每个点精确当边界的假设本身不能无条件接受；这种偏差也不能仅靠 2.58×10⁻⁷ 的中心提取尺度解释。它可能来自求解误差、显示的近边界点或未记录的生产处理，本次不指定原因。

### 4.2 允许统一边界纵坐标误差的全部割线诊断

为避免仅使用一对短割线，固定显示 x，对全部上/下点对 i<j 计算在 x_q=.105885098499 的延长值

\[
a_{ij}=y_j+t(y_j-y_i),\qquad t=(x_q-x_j)/(x_j-x_i)>0.
\]

若每个显示纵坐标与真实上/下边界差至多 δ，则凸性必需满足

\[
l(x_q)\ge\max_{ij\in\text{下边}}[a_{ij}-(1+2t)\delta],
\quad
u(x_q)\le\min_{ij\in\text{上边}}[a_{ij}+(1+2t)\delta].
\]

这是**给定误差假设下的必要条件**，不是拟合模型，也不是对作者数值误差的估计。结果如下：

| 假定的统一 δ | 对 l(x_q) 的必要下界 | 对 u(x_q) 的必要上界 |
|---|---:|---:|
| 0 | −.00620463901 | −.00845829029 |
| 中心读数尺度 2.57506×10⁻⁷ | −.00621369899 | −.00844974058 |
| 已见上边非凹偏差 3.44432×10⁻⁵ | −.00664664029 | −.00738295306 |
| 显示圆点纵向半径 6.12091×10⁻⁵ | −.00677296253 | −.00712384694 |
| 1.04647405×10⁻⁴ | −.00690407576 | −.00690407576 |

前四行下界都高于上界，无法容纳该 x 的任何纵坐标。容纳 **任何**高度至少需要 δ≥**1.04647405×10⁻⁴**；起作用的上下点对分别是 (277,288) 和 (323,344)。若还要求当前候选的实际 y=−.006854817981，则必要 δ 至少 **1.18111944×10⁻⁴**，主要来自上边点对 (275,288)；下边单独要求至少 8.65996×10⁻⁵。

这些阈值约是中心读数尺度的 406 倍、459 倍；显示圆点半径一行仅帮助建立视觉尺度，**不把圆点半径赋予数值误差含义**。计算固定提取的 x；未做 x/y 联合误差认证，也未把 δ 阈值当成充分条件。最重要的限制仍是作者没有给出这类边界误差上限，所以本表不能升级为排除隐藏尖端的无条件证明。

## 5. 对 B3 比较和验收的含义

1. 正确的图形交付范围是 **x≥0 的闭包**。应比较该范围内的凸集、同法向支持函数和共同 x 的上下切片；不要把径向 α 与支持法向直接按索引配对。改显示范围不改变任何物理约束。
2. 从有限标记集 S 只能得到一个显示内包络 conv(S)。即使假定这些点可行，conv(S) 与 conv(S∪{更远点}) 都与“包含这些点”相容。因此 maxsample 本身没有严格外界效力；当前支持 gap 与论文扫描分辨率应单独记录。
3. 缺少原始扫描协议使漏尖端不能被严格排除，但普通画框裁切和读数误差已不足解释。近等 x 点列、约 16 步的差距以及附条件凸性检验表明，**目前没有证据把全部右端偏差归因于径向采样**。也没有依据把偏差归因于论文错误。
4. 本次结果不选择 B、不更换范数或物理约束。当前报告应保留“本项目有限支持已闭合；与论文显示右端仍有未解释差异”的口径。完整 B2/B3 区域、共同 regulator 平台及分辨率稳定性仍应按已声明方案验收；若能获得作者 Fig.4 扫描命令/原始点及容差，可直接解决本报告保留的中心、漏点和边界误差歧义。

复算来源仅为上述 CSV、report.json 和本地 TeX/PDF；几何计算使用原双精度坐标的线性拟合、atan2、凸/凹包络及全部割线枚举。未创建执行模块或新的优化脚本。
