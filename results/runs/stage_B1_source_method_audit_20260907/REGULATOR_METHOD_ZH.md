# Regulator规范、共同B与预先定义的平台检验

2026-09-07。核对结论：**2403公开程序的B=377500执行解释没有发现漏掉的整体ρ缩放；但直接把这个数搬到当前pure/六种χ问题，没有完成作者所要求的regulator平台检查。** 固定B的primal/dual间隙闭合，只证明该有限问题已求解，不证明它已不受regulator影响。本报告只研究来源与协议，没有改变B、优化或修改核心。

## 来源究竟要求什么

[2103.11484v3 §3.3](https://arxiv.org/html/2103.11484v3#S3.SS3)先给正则化约束\(\|\alpha\|\le M_{reg}\)，再明确通过增大regulator寻找最大值平台；对偶也采用同一选择原则。范数并不唯一：该文§3.37讨论核加权的对偶范数，§5.40的基底实现采用平方范数。因此，2021不同范数／基底里的数字不能直接当作2024普通L4上界。

[§6、Fig.3–4](https://arxiv.org/html/2103.11484v3#S6)展示跨多个数量级的平台，并同时改变primal插值点数、dual展开维数，用上下夹逼判断稳定。文中将更大regulator下的再次上涨或随机涨落归为数值误差区；其图的log-regulator横轴还作了水平平移以叠加不同曲线。这是具体数值诊断，**不是允许按喜好丢弃任何后段上涨的普遍定理**。

[2403.10772v4 §8.4](https://arxiv.org/html/2403.10772v4#S8.SS4)引用这套方法并写Mreg=100；[附录B.1](https://arxiv.org/html/2403.10772v4#A2.SS1)增加M、spin、BSpline数和regulator作稳定性比较。它不能替代当前全部pure/χ方向的平台检查，也没有给2309v3的regulator归一化作唯一恢复。

## 整体ρ缩放追踪：没有另一个隐藏的Mrho或π因子

公开MATLAB代码是

```matlab
Mrho = M^2 + M*(M+1)/2;
variable rho(Mrho)
Imht = B2*rho+B1*sig; Reht = A2*rho+A1*sig;
norm(rho/Mrho,4) <= 100;
```

故定义\(d_M=M^2+M(M+1)/2\)，执行约束为
\[
\|r\|_4\le B(M)=100d_M,\qquad
r=(\rho_{1,ij},\rho_{2,ij},\ i\le j\text{ for }\rho_2).
\]
M50时\(d_M=3775\)，B=377500。这里的ρ₂是actual上三角；本repo的C_flat off=2ρ₂须先除2再计算范数。[源码10、53、60、63行](https://github.com/hyfysics/gauge-theory-bootstrap/blob/arxiv-2403.10772/theories/qcd/papers/arxiv-2403.10772/GTB_numerics.m#L10-L65)。

检查了从色散式到MATLAB的整条变量链：

| 可能混淆的缩放 | 来源中的实际作用 | 是否另缩放振幅ρ变量 |
|---|---|---|
| 2021的ρ₂核含1/(2π²)及两项 | 利用ρ₂对称性，两项积分相等，恰等于2403的1/π²单项 | 否，不缺整体2 |
| 物理变量x映射到φ | Jacobian吸收进核，ρ仅重命名为ρ(x(φ),y(φ′)) | 否 |
| Δφ、Δφ²及1/π | 明确出现在单／双谱积分矩阵中 | 否，不能再乘M²或π²到ρ |
| κ与Λ的幺正重缩放 | `A2=A/LambdaI`、`B2=B/LambdaI`、`Bhat2=B/LambdaI^2`按物理行缩放 | 否，属于输出行，不是ρ列 |
| 减除点ν₀ | 改变常数和single-density坐标，双密度不变 | 否 |
| ρ₂对称化及upper取列 | `2*symtr`，diag再/2，保留actual上三角 | 只有明确packing，无额外全局因子 |
| 电流谱的运动学重缩放 | 作用在独立`specC`／current谱，不是振幅`rho` | 否 |

证据：[2021式2.16c–d](https://arxiv.org/html/2103.11484v3#S2.SS2)、[2403式2.1](https://arxiv.org/html/2403.10772v4#S2.SS1)、[φ映射与核权重式8.17–8.23](https://arxiv.org/html/2403.10772v4#S8.SS2)；本地notebook的[Ap1](/home/shiqiu/s-matrix-bootstrap/references/upstream-gauge-theory-bootstrap/theories/qcd/papers/arxiv-2403.10772/GTB_numerics.nb:1316)、[Kunphys](/home/shiqiu/s-matrix-bootstrap/references/upstream-gauge-theory-bootstrap/theories/qcd/papers/arxiv-2403.10772/GTB_numerics.nb:1668)、[rho块拼接](/home/shiqiu/s-matrix-bootstrap/references/upstream-gauge-theory-bootstrap/theories/qcd/papers/arxiv-2403.10772/GTB_numerics.nb:2951)、[选取物理行](/home/shiqiu/s-matrix-bootstrap/references/upstream-gauge-theory-bootstrap/theories/qcd/papers/arxiv-2403.10772/GTB_numerics.nb:3230)、[Λ行缩放](/home/shiqiu/s-matrix-bootstrap/references/upstream-gauge-theory-bootstrap/theories/qcd/papers/arxiv-2403.10772/GTB_numerics.nb:4331)。

所以代码与文字的“100”应表述为**明确的归一化范数约定尚须区分**，不能通过再猜一个ρ缩放把377500改成100。2021 scalar图里的π/4显示归一化，也不是pion双密度上界的换算系数。

## 对当前已闭合点能立即作出的数学判断

固定H、κ、χ范数及ε、自由常数约定和支持方向d，记
\[
h(B)=\max\{d\cdot f:\text{其余约束固定},\ \|r\|_4\le B\}.
\]

它单调不减，且关于B是凹函数：约束集在(r,B)中凸，或者从对偶看，h是合法仿射上界\(C_k+B R_k\)的下包络。这里\(R_k\ge0\)是原变量残差的4/3范数，C包含disk和χ等支持项。因此，同一旧dual可以在新B重新给出
\[
U_k(B')=C_k+B'R_k.
\]

若已有\(h(B)\in[L,U]\)，且该dual的density项\(D=B R_k\)，则
\[
h(B)-h(B/10)\ge L-[U-0.9D]=0.9D-(U-L).
\]

以本次给出的PV支持区间约[.10588510,.10594018]、density项约.0105估算，右边约.00939。这说明当前点并没有得到“向前一整decade仍几乎不变”的证据，甚至可用旧dual直接排除这种窄平台。**显示值只用于量级判断；严格结论应由保存的原dual按B/10重新验算，不应直接减几个经过舍入的报告数字冒充证书。**

ρ范数接近cap本身不是平台否定条件：近零方向可以吸收大系数而几乎不改物理量。但闭合间隙加上上述dual斜率，比单看cap占用率强得多。反过来，若后段上涨有独立区间证明且随分辨率仍存在，就应承认有限模型的regulator依赖，不能仅因为2021图的说明就删掉它。真正违反B单调性的“已认证区间”则要求检查证书或问题是否已改变。

## 建议的预注册协议：不使用Fig.4端点选B

以下是本repo可执行的验收建议，**具体网格和数值阈值不是作者原文给出的定理或参数**，应在新的扫描前固定。已知B377500结果保留作既有基线，Fig.3/4的目标点、形状和端点不进入选B规则。

1. **冻结问题。** 固定处方、ν₀、M50/L10、完整原生H、T₀策略、actual-ρ L4定义、χ范数、六个ε及支持方向；只改B。不同solver/数值坐标可以比较，但结果均交给同一原H验收。不能在扫描中同时补新物理行、换χ范数或改density正性。
2. **冻结log序列。** 若根任务已登记序列，沿用它。否则建议在\(a=B/d_{50}\)上取\(a=10^k,k=-4,-3,\ldots,3\)，即B从.3775到3.775e6，包含公开代码点a=100。任何向外扩展仍只按相同十倍规则，并如实保留失败；不在“接近论文端点”的位置加密。
3. **先廉价筛选。** 先用当前敏感的χ ε=.002、+x，以及pure +x检查是否存在候选窗口。保存的dual可按新B重算上界；primal若actual norm≤新B也可重验复用。没有必要每个B都从头优化。但少量pilot不能证明全部曲线稳定。
4. **再检查共同窗口。** 候选窗口须至少包含3个预定十倍间距点、覆盖两个数量级，并对pure及六个ε同时成立。使用已冻结的区域方向表；至少先检查±x、±y及垂直于tree-level直线的\(\pm(1,15)/\sqrt{226}\)。最终稳定性结论须覆盖实际用于B2/B3区域的全部方向，不能把+x平台迁移给整片区域。
5. **用区间定义平台。** 对同一模式、方向，在窗口端点\(B_a<B_b\)计算或复用有效\([L_a,U_a]\)、\([L_b,U_b]\)。预置\(\tau=10^{-6}+0.01\max(|L_a|,|U_a|)\)，并要求每个求解间隙≤\(\min(10^{-4},\tau/5)\)。若\(U_b-L_a\le\tau\)，由B单调性可控制整个窗口；若\(L_b-U_a>\tau\)，明确排除平台；其余归为未分辨，不能算通过。也可用小B的可行内多边形与大B的合法外多边形控制区域几何距离，避免仅靠视觉重叠。
6. **共同B的选择规则。** 取按扫描顺序遇到的、满足全部模式／方向条件的第一个共同窗口，在已预定网格中选择最靠近其几何中点的B；平手取较小值。pure与六ε共用这一B。若交集为空，就记录“无共同regulator稳定窗口”，不得每条曲线分别挑B来制造嵌套。
7. **独立分辨率检查。** 在候选B附近至少重做M60/L10及M50/L12，与M50/L10比较；使用相同方向及平台判据。采用作者代码规则时，跨M保持a=B/d_M固定，明确报告实际B(M)。重新检查相邻log-B点，确认窗口没有随分辨率移走。不要假设改变M后的collocation问题是嵌套的；增加L只有在共同物理行确实保持时才具有加约束的单调性。
8. **保留缺失数据。** 超时、InsufficientProgress或无法闭合的点属于未测清，不是平台点、不是不可行证明，也不能填成零目标。最新B100/B1000的native失败说明数值求解还可能困难，不能用失败反推regulator曲线。

1%的平台阈值只是一项预先给定的有限原型稳定性口径；如果后续目标需要更精细的区域宽度，应先声明更严格口径再重测，不能看到结果后切换阈值来保住“通过”。

## 跨分辨率的B：三种不同约定不能混写

公开代码保持\(\|r/d_M\|_4\le a\)，即B(M)=a d_M。这不等于固定ordinary B；也不等于固定\((d_M^{-1}\sum|r_i|^4)^{1/4}\)，后者对应B随\(d_M^{1/4}\)变化。对于采样一个平滑密度，普通向量L4本来会随点数增长。若要改成带Riemann权重的函数范数，还须处理ρ₂全对称积分中off项的双计数，是另一个具名regulator定义。

本轮优先沿作者**代码**规则做分辨率对照，报告a和B两者；只有宽平台确认后，才有理由说这种适度归一化变化不影响目标。不能把B377500机械地固定到所有M，又同时声称复现了作者固定a=100的比较。

## 可以迁移什么，不能迁移什么

| 变化 | 可以保留／重用 | 必须重新核验 |
|---|---|---|
| 同H改变B | 满足新cap的primal；旧dual及其\(C+B'R\)上界 | actual-ρ norm、完整原H可行性、用新B算支持界 |
| 同H改变ε | 更小ε可行点通常仍可用于更大ε／pure；有限ε之间可重算旧χ dual成本 | 新χ范数；pure不能直接沿用非零χ乘子的成本项 |
| 六个ε共同作图 | 同一个B、同一个物理约束集合和同一坐标 | 每种ε自己的支持界；pure稳定不推出χ稳定，反之亦然 |
| 改M、ν₀或处方 | 数学公式、生成代码、初值建议 | 核、ρ坐标／范数、全约束、上下界；旧rank/可行证书不迁移 |
| 仅改可逆数值坐标／仿射平移 | 同一物理问题与原变量度量 | 输出还原与原H证书；solver的scaled norm不是物理B |

## 足以声称什么

“固定B的有限问题已求解”需要原H可行点及该B的有效支持间隙；当前一些点已经达到这一层。“paper-style有限原型稳定”还需要预注册多数量级共同B窗口、实际作图方向的稳定性、至少M/L独立变化、ρ度量和全部处方一致，并保留未收敛点。它仍不是连续能量／无限spin幺正证明，也不自动完成Fig.3/4形状复现。若平台与论文端点不一致，应继续查来源或报告差异，不能反过来选择B追逐.082573。
