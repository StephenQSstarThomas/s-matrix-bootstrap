# A–C完整性及D–F精度就绪审计

结论：在目前实际执行的、具名PV/M50有限模型内，未发现归一化、交叉组装、幺正公式、相位定义或电流Gram的重大代数错误。当前C代表振幅在768-bit重新计算的全部1500个原生分波上通过幺正检查。**这支持已有方法复现，但不构成“完整物理性质已经证明”或“高精度极值振幅已经复现”的保证。** 下一批宜明确承诺D1、D2两步，把D3作为独立验收的第三步，而不一次承诺D–F九步的物理精度。

本次仅做4次顺序有限求值和必要的已有数据核对，没有优化、范数/参数扫描、处方切换或核心源码改动。[A–C数值证据](AC_CHECKS.json)与[D1/D2独立审计](D12_AUDIT_ZH.md)记录原始结果。

## 当前精度究竟受什么限制

**算术精度不是现有C曲线的主要限制。** 同一代表的384/768-bit结果在导出的float64数值中完全一致；已存float64 H的高精度收缩与768-bit重新生成PV核的完整原生f比较，最大差约6.14e−11。这只是此系数向量的检查，不是所有B点或未来D解的统一误差界，更不是384-bit物理预测精度。

**C2的凸组合会真实改变非弹性和相移。** 两个父振幅投影分别约(.0759108,−.00429876)、(.0631586,−.00341244)，当前权重约(.796943,.203057)。对未舍入组合，

Sλ=(1−λ)Sa+λSb，

1−|Sλ|²=(1−λ)(1−|Sa|²)+λ(1−|Sb|²)+λ(1−λ)|Sa−Sb|²。

它保留幺正盘，却增加额外非弹性余量。此次S0的该附加项最大约.12159；父振幅η最低约.99929/.99834，组合后为.93648。父振幅相移最大跨度为S0 25.71°、S2 10.96°、P1 3.64°。父点的投影和IR耦合不同，因此这些跨度是代表选取敏感性，不是固定xref上的严格相移误差区间。B的.01区域误差不控制这种全振幅/相移差别。

原C2已明确是可行近边界振幅，故没有发现幺正公式错误；但若将它称为高精度极值解或用其区域误差给相移定精度，会构成过度主张。高精度C/E对照应使用统一、预先固定的真实极值选点规则，或单独量化插值效应；不得通过强制η=1或按实验重选点来修补。这个补强可与D1/D2分开准备，不需要重扫整个B区域。

**D2截止求积有显著系统敏感性。** 对同一常谱ρ=1，原hard-midpoint/M50四矩相对误差为14.64%/28.86%/4.57%/14.64%；现有clipped-phi为.917%/2.855%/.106%/.917%。这是诊断，不是未知实际谱的误差界。它说明截止处理须在D2中明确并处理，不能用更多Arb位数消除，也不能自动宣称切到clipped就得到1%物理精度。

四矩raw容差.002相对各目标分别约83.85%/1.79%/47.30%/1.37%。这是允许集合的约束宽度，不是算法算错了这些百分比；也不能直接换算为相移误差。打印矩值、mq规则、OPE截断与输入假设须分别记录，不能通过改它们贴合实验。

**ρ质量不能仅靠提高bits定精度。** 原M50在.770GeV附近相邻节点约.731675与.792136GeV，间隔约60.5MeV。若仅用节点夹住90°交叉，得到的是节点区间。更细的质量估计可以使用明确的插值及分辨率检验，但图上的插值值不能冒充严格质量界；当前还没有UV联合相移，因此没有可预先保证的ρ质量误差。

## D–F逐步评估

| 步骤 | 当前可推进程度 | 精度验收重点 |
|---|---|---|
| D1 | 可以作为下一批第一步 | 实际M50/PV的4076变量、100个3阶PSD；同一S0/P1接线，独立实/复Gram测试进入活跃测试 |
| D2 | 可以作为下一批第二步 | 四矩、单位、原始/归一化容差、截止处理、质量规则和14个FF锥；先固定数值积分处方及其误差诊断，不拟合图形 |
| D3 | 有条件的第三步，尚不能预保证通过 | 当前没有联合求解接口；需共同幅度的联合可行点，并核验所有散射盘、χ、密度、100 PSD、四矩和FF caps |
| E1 | 等D3及联合支持验证 | 原B上界可作为松界，但不能代替含电流PSD/FESR/FF乘子的紧联合对偶证书 |
| E2 | 等有效联合区域 | 固定实际极值代表点/同一选点规则；不把凸组合当唯一精确边界振幅 |
| E3 | 等E2完整联合系数 | 同一幅度的三相移/η和ρ交叉；先报告观测量及范围，不先承诺百分比精度 |
| F1 | 需真实联合解后执行 | 论文五组(M,L)=(50,8)/(50,10)/(50,12)/(45,10)/(60,10)，同一物理输入与选点规则；明确B是否随M改变 |
| F2 | 本次只覆盖其中部分检查，不能计完成 | 联合原式审核、矩阵舍入、选点及分辨率敏感性，所有求值尊重PV的定义域；不将连续认证无条件扩展为新主线 |
| F3 | 等上述结果 | 把算术/求解误差、求积/截断、代表点依赖、UV输入假设分别列出，据证据报告可支持的精度 |

D3的联合原式支持验证器必须包含新增变量和全部对偶项。不能让无界电流变量的未消除残差被旧ρ密度范数吸收；不能以B的径向缩放默认修复整个联合解，因为F(0)=1、FESR及FF条件也必须一起满足。若采用凸组合修复，需要一个已验证的完整联合可行参考解，并混合全变量。

实际执行建议是“D1→D2，独立验收后D3单个M50联合试解→联合原式核验”，之后再扩展到E。F1/F2的少量代表结果核对可在大范围E扫描之前作为早期反馈，但不冒充完整F阶段。保持单个科学作业和明确预算，不再启动大并发、无目标范数扫描或求解器轮换。

## 关于保证

能保证的是某个明确有限问题中已验算的代数关系、约束和数值区间。尚不能无条件保证物理精度、唯一QCD振幅、全连续幺正性或九个后续步骤都达到预定百分比。下一轮高可信承诺范围为D1/D2两步；D3是第三个实际结果关口。更高物理精度必须由后续联合解、分辨率和观测量稳定性来证明，而不是由完成步骤数或更大的计算预算来推断。
